# lp-sample

ランディングページ制作のサンプル置き場です。

`index.html` の1ファイルで完結しており、ビルドは不要です。
静的ホスティング（GitHub Pages / Vercel など）にそのまま置けます。

## 現在のサンプル

**自己紹介LP** — 架空のデザイナー「にしむら はる」の自己紹介ページ。

- 構成: ヒーロー → 共感 → できること → お問い合わせ
- 丸ゴシック体、セージグリーンとアプリコットのやわらかい配色
- ライト／ダークの両テーマに対応
- JavaScript 不使用

## 注意

掲載している人物・実績・料金はすべて**架空**です。
デモ用途以外に転用する場合は、ページ上部と末尾のデモ表記を必ず差し替えてください。
ボタンのリンク先も設定されていません。

## ローカルで見る

`index.html` をブラウザで直接開くだけで表示できます。
